# bk-bot

Telegram-интерфейс продукта.

## Здесь будет

- запуск и завершение работы бота;
- команды, кнопки и обработчики событий;
- пользовательские сообщения и состояния диалога;
- преобразование Telegram-событий в запросы к backend;
- единая обработка ошибок для пользователя.

## Здесь не должно быть

- прямой работы с Google Sheets;
- ключей и токенов;
- сложных бизнес-правил;
- прямой зависимости от GigaChat.

## Перед началом разработки

Нужно выбрать Telegram-фреймворк, формат запуска (polling или webhook), правила текстов и состояний. Решение фиксируется в Issue и [архитектуре](../docs/architecture.md).
