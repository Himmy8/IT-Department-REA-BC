# Как внести вклад

Спасибо, что помогаете развивать IT-направление БК РЭУ. Этот файл — короткая памятка; полный процесс описан в [GitHub workflow](docs/github-workflow.md).

## Перед началом

1. Найдите существующую Issue или создайте новую.
2. Уточните ожидаемый результат и способ проверки.
3. Назначьте ответственного.
4. Создайте ветку от актуальной `main`.

## Требования к изменению

- Одна ветка и один Pull Request решают одну понятную задачу.
- Новая логика сопровождается проверкой или понятным сценарием ручного тестирования.
- Изменения интерфейса согласованы с дизайнером из медиа-отдела.
- Изменение структуры Google Sheets отражено в документации интеграции.
- Секреты и персональные данные не попадают в код, логи и скриншоты.

## Готово, когда

- критерии приёмки выполнены;
- проверка пройдена;
- документация обновлена;
- Pull Request одобрен владельцем затронутой области;
- после объединения `main` остаётся рабочей.
