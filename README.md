# IT-направление Бизнес-клуба РЭУ

Единое рабочее пространство команды, которая развивает цифровые продукты Бизнес-клуба РЭУ.

Главный продукт — **Telegram-бот БК РЭУ**. Он будет работать с внутренним backend, обязательно синхронизироваться с Google Sheets и в дальнейшем сможет использовать AI, включая GigaChat.

## Структура проекта

```text
bk-bot/         Telegram-интерфейс: команды, кнопки, сообщения
backend/        Бизнес-логика и внутренний API
integrations/   Подключения к Google Sheets, AI и другим сервисам
docs/           Простая документация о продукте и процессах
.github/        Шаблоны задач, pull request и ответственные
```

В каждой папке есть свой `README.md` с объяснением: что здесь хранится, что сюда не класть и с чего начинать.

## Как мы работаем

1. Создаём задачу через подходящий шаблон GitHub Issue.
2. Назначаем ответственного и фиксируем понятный результат.
3. Создаём отдельную ветку от `main`.
4. Вносим небольшие, проверяемые изменения.
5. Открываем Pull Request, проходим проверку и объединяем через squash merge.

Подробности и примеры названий веток есть в [GitHub workflow](docs/github-workflow.md).

## Важные правила

- `main` должна оставаться рабочей.
- Пароли, токены и ключи нельзя добавлять в Git.
- Google Sheets — обязательная интеграция, но бизнес-логика не должна зависеть от формата конкретной таблицы.
- AI — дополнительный модуль: базовые функции бота должны работать без него.
- Дизайнер относится к медиа-отделу и подключается через понятный бриф и дизайн-ревью.
- Любое изменение должно быть понятно следующему участнику команды.

## Текущий этап

Сейчас заложен организационный каркас. Конкретный язык, фреймворк, схема деплоя и структура данных фиксируются отдельными решениями после уточнения требований, чтобы не создавать лишнюю сложность заранее.
