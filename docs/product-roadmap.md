# План развития

Это ориентир, а не жёсткий календарь. Каждая функция создаётся через отдельную Issue.

## Этап 0 — основа команды

- [x] Понятная структура репозитория.
- [x] Шаблоны Issue и Pull Request.
- [x] Правила работы, роли и безопасность.
- [ ] Назначены владельцы компонентов.
- [ ] Выбран и зафиксирован технологический стек.

## Этап 1 — минимальный Telegram-бот

- [ ] Согласованы основные пользовательские сценарии.
- [ ] Создан каркас бота и конфигурация окружения.
- [ ] Реализованы команды запуска, помощи и обработки ошибок.
- [ ] Подключены логи без персональных данных и секретов.

## Этап 2 — Google Sheets

- [ ] Назначен владелец таблицы.
- [ ] Зафиксирована схема вкладок и колонок.
- [ ] Настроен сервисный аккаунт с минимальными правами.
- [ ] Реализованы чтение, запись, валидация и обработка недоступности.
- [ ] Подготовлен резервный сценарий и правила изменения схемы.

## Этап 3 — эксплуатация

- [ ] Выбран хостинг и способ запуска.
- [ ] Настроены тестовое и рабочее окружения.
- [ ] Добавлены автоматические проверки, мониторинг и резервное копирование.
- [ ] Описан выпуск новой версии и откат.

## Этап 4 — AI / GigaChat

- [ ] Найден конкретный сценарий, где AI даёт измеримую пользу.
- [ ] Согласованы безопасность данных, лимиты и стоимость.
- [ ] Создан независимый AI-адаптер.
- [ ] Добавлены проверка качества и безопасный fallback без AI.
