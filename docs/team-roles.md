# Роли команды

Один человек может совмещать несколько ролей. Роль описывает ответственность, а не должность.

| Роль | Отвечает за | Не решает единолично |
|---|---|---|
| Руководитель IT | приоритеты, архитектурные решения, доступы, итоговое качество | задачи и дизайн медиа-отдела |
| Владелец продукта | потребности клуба, критерии готовности, порядок функций | технический способ реализации |
| Разработчик бота | Telegram-сценарии, команды, сообщения, обработка событий | структуру Google Sheets без владельца интеграции |
| Backend-разработчик | бизнес-правила, внутренний API, надёжность | визуальные и редакционные решения |
| Владелец Google Sheets | схему таблиц, права, качество и миграции данных | общую архитектуру продукта в одиночку |
| Ответственный за AI | AI-адаптер, качество, ограничения и стоимость | обязательные сценарии без согласования с продуктом |
| Тестировщик | сценарии проверки, регрессия, фиксация ошибок | изменение критериев задачи после разработки |
| Дизайнер медиа-отдела | пользовательский сценарий, тексты, кнопки, визуальная целостность | приоритеты IT-бэклога и техническую реализацию |

## Владелец задачи

У каждой Issue должен быть один ответственный. Он не обязан выполнять всю работу сам, но следит, чтобы задача была понятна, не зависла и дошла до проверяемого результата.

## Кто проверяет изменения

- `bk-bot` — ответственный за бота;
- `backend` — ответственный за backend;
- `integrations/google-sheets` — технический владелец интеграции и владелец данных;
- `integrations/ai` — ответственный за AI;
- пользовательский интерфейс и тексты — дизайнер или назначенный представитель медиа-отдела;
- доступы и секреты — руководитель IT.

Пока GitHub-логины команды не закреплены, `@Himmy8` указан резервным владельцем всех областей в CODEOWNERS.
