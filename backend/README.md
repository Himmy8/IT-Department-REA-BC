# backend

Бизнес-логика и внутренний интерфейс между Telegram-ботом и внешними системами.

## Здесь будет

- правила и сценарии продукта;
- модели внутренних данных;
- проверка входных данных и прав;
- внутренний API или сервисный слой;
- обработка ошибок, логирование и проверки.

## Здесь не должно быть

- Telegram-специфичных кнопок и объектов;
- названий колонок Google Sheets внутри бизнес-правил;
- секретов внешних систем;
- логики, обязательной только для одного AI-провайдера.

Backend должен быть проверяемым отдельно от Telegram, таблиц и AI.
