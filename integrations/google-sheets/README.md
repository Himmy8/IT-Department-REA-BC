# Google Sheets

Обязательная интеграция для хранения и обмена рабочими данными на первом этапе.

## Ответственность модуля

- подключение через отдельный сервисный аккаунт;
- чтение и запись согласованных диапазонов;
- преобразование строк таблицы во внутренние модели;
- проверка обязательных колонок и типов;
- понятное поведение при пустых данных, лимитах и недоступности API.

## До реализации нужно зафиксировать

| Вопрос | Решение |
|---|---|
| Кто владелец таблицы? | Не назначен |
| Какие вкладки используются? | Не определено |
| Какие колонки обязательны? | Не определено |
| Что можно читать и изменять? | Не определено |
| Как идентифицируются записи? | Не определено |
| Как изменяется схема? | Через отдельную Issue и миграционный план |

## Правила

- Код backend не обращается к таблице напрямую.
- Имена вкладок и колонок сосредоточены в этом модуле.
- Изменение структуры таблицы сначала документируется и проверяется на тестовой копии.
- Сервисному аккаунту открывается только нужная таблица и только необходимые права.
- В тестах используются фиктивные данные без персональной информации.

Переменные окружения перечислены в [`.env.example`](../../.env.example), правила доступа — в [документе о секретах](../../docs/secrets-and-access.md).
