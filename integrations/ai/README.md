# AI / GigaChat

Будущий необязательный модуль для AI-функций. Он добавляется только под конкретный полезный сценарий.

## Принципы

- Основные функции бота работают без AI.
- Backend обращается к единому AI-интерфейсу, а не напрямую к GigaChat.
- Провайдера можно заменить без переписывания бизнес-логики.
- Для каждого запроса есть таймаут, лимит и безопасный fallback.
- Персональные или закрытые данные не отправляются модели без отдельного согласования.
- Ответы AI не считаются достоверными без необходимых проверок.

## Перед подключением

Нужно определить сценарий, ожидаемую пользу, допустимые данные, стоимость, лимиты, метрики качества и поведение при недоступности сервиса. После этого создаётся отдельная Issue и техническое решение.
