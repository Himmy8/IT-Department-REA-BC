# integrations

Адаптеры для внешних систем. Каждый сервис живёт в своей папке и преобразует внешний формат во внутренний формат проекта.

## Интеграции

- [Google Sheets](google-sheets/README.md) — обязательная интеграция первого этапа.
- [AI / GigaChat](ai/README.md) — необязательная будущая интеграция.

## Единые требования

- таймауты для внешних запросов;
- понятные ошибки и ограниченные повторы;
- отсутствие секретов в коде и логах;
- минимальные права доступа;
- возможность тестирования без обращения к реальному сервису;
- документированное преобразование данных.
